UNIMED VITÓRIA - GESTÃO DE TREINAMENTOS

COMO ABRIR
1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra a pasta extraida.
3. De dois cliques em UnimedVitoriaTreinamentos.exe.

REQUISITOS
- Windows 10 ou Windows 11 de 64 bits.
- O Microsoft Edge WebView2 Runtime. Ele ja vem instalado na maioria dos
  computadores Windows 10/11. Se o aplicativo informar que esta faltando,
  instale-o pelo site oficial:
  https://developer.microsoft.com/microsoft-edge/webview2/
- Nao e necessario instalar Python nem manter conexao com a internet para
  usar o aplicativo depois que ele estiver instalado.

DADOS E PRIVACIDADE
- Para preservar a compatibilidade com os dados ja existentes, o banco de
  dados continua no perfil local do usuario, em:
  %LOCALAPPDATA%\Controle Treinamentos SOS\sos.db
- Os dados nao sao sincronizados entre computadores. Para trocar de computador,
  transfira esse arquivo por um meio aprovado pela empresa e substitua o banco
  no destino com o aplicativo fechado.
- O pacote nao inclui banco de dados nem dados pessoais.
- Os registros de treinamentos existentes sao preservados ao atualizar o aplicativo.

ACOMPANHAMENTO DOS TREINAMENTOS
- Cada tema tem 60 dias para atingir 100% dos colaboradores ativos, contados
  a partir da data da primeira turma cuja frequencia foi salva.
- O painel lista treinamentos concluidos, em andamento, atrasados e ainda nao iniciados.
- A tela "Cobertura por Tema" mostra a data de inicio, o prazo e os colaboradores pendentes.
- Os temas exibidos sao os das turmas cadastradas. "Limpar todos os dados" tambem
  remove esses temas; eles nao voltam ao reiniciar o aplicativo.
- Na aba "Turmas e Presenca", use "Excluir" para remover uma turma. A exclusao
  tambem remove as frequencias vinculadas e recalcula a cobertura do tema.
- Temas escritos com diferenca apenas entre maiusculas e minusculas sao agrupados
  como o mesmo tema na cobertura.
- Ative "Avisos do Windows" no painel e permita as notificacoes para receber avisos
  sobre novos temas, inicio do prazo de 60 dias, conclusao em 100% e atrasos.
  Os avisos funcionam enquanto o aplicativo estiver aberto, inclusive minimizado.

IMPORTAR PARTICIPANTES DE UMA PLANILHA
- Na tela Participantes, clique em "Importar Excel" e selecione um arquivo .xlsx.
- A primeira linha deve conter os cabecalhos Matrícula, Nome e Cargo.
  E-mail e opcional. Tambem sao aceitos os nomes Mat, Funcao e Email.
- Cada linha seguinte representa um participante. Linhas sem dados sao ignoradas.
- Matriculas ja cadastradas sao ignoradas e os cadastros existentes nao sao alterados.
- Salve matriculas como texto no Excel para preservar zeros a esquerda.
- Use o botao "Novo cargo" na tela Participantes para cadastrar cargos reutilizaveis.
- Use "Remover cargo" para excluir cargos sem participantes associados. Cargos em uso precisam ser reatribuidos antes da remocao.
- A opcao "Limpar todos os dados" tambem apaga todos os cargos cadastrados.

Se o aplicativo nao abrir, contate o suporte de TI e informe o erro exibido.
